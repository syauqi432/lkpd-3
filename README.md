Refleksi

1. Mengapa branch diperlukan?
Branch berfungsi untuk memisahkan proses pengembangan dari kode utama. Dengan adanya branch, kita dapat mencoba fitur baru atau melakukan perbaikan tanpa mengganggu proyek yang sedang berjalan di branch "main".

2. Apa keuntungan bekerja pada branch dibanding langsung di main?
Menggunakan branch membuat proses pengembangan menjadi lebih rapi dan aman. Semua perubahan dapat diperiksa serta diuji terlebih dahulu sebelum digabungkan ke "main", sehingga kualitas kode utama tetap terjaga.

3. Kapan sebaiknya membuat branch baru?
Sebaiknya branch baru dibuat setiap kali akan mengerjakan fitur baru, memperbaiki kesalahan (bug), atau melakukan perubahan yang cukup besar. Dengan cara ini, setiap pekerjaan menjadi lebih teratur dan mudah dikelola.
